# Starforge Idle Support

For support, open an issue at:

https://github.com/manuelferreira28ya-sudo/StarforgeIdle/issues

Please include:

- Device model
- iOS version
- App version
- A short description of the issue

Known local-only behavior:

- Progress is stored on the device.
- Deleting the app can delete local progress.
- This build has no ads, purchases, accounts, or cloud sync.

# Asset Sources

Starforge Idle uses original SwiftUI layout plus small permissively licensed RPG icons imported for the Void Frontier RPG layer.

- OpenGameArt: "RPG UI Icons" by OwlishMedia, licensed CC0. Imported selected PNG icons for battle, weapons, armor, potions, relics, elements, and rewards.
- OpenGameArt: "16x16 Assorted RPG Icons" by Shade, licensed CC0. Evaluated as an item library reference for future larger inventory art.
- Kenney: "Roguelike/RPG pack", licensed Creative Commons CC0. Evaluated as a larger tile/unit reference source for future map or sprite expansion.

The app should not use copyrighted App Store game art, names, characters, or UI assets. These sources are suitable for commercial game prototypes under CC0-style terms, but keep this file updated whenever assets are added or replaced.

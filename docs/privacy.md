# Starforge Idle Privacy Policy

Effective date: May 11, 2026

Starforge Idle does not collect personal data, does not track users, and does not contact third-party advertising or analytics services in this build.

The app stores game progress locally on the device using Apple UserDefaults. Local progress can include stardust totals, generator counts, upgrade levels, goal completion, daily streak state, crew unlocks, and the last save time. This data stays on the device unless the user or operating system backs up app data through standard Apple device backup features.

Starforge Idle does not require account creation, location access, contacts, photos, microphone, camera, push notifications, or network access in this build.

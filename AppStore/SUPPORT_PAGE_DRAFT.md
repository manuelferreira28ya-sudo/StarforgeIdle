# Starforge Idle Support Template

Thanks for playing Starforge Idle.

For support, include:

- Device model
- iOS version
- App version
- A short description of the issue

Known local-only behavior:

- Progress is stored on the device.
- Deleting the app can delete local progress.
- This build has no ads, purchases, accounts, or cloud sync.

Support: https://github.com/manuelferreira28ya-sudo/StarforgeIdle/issues
